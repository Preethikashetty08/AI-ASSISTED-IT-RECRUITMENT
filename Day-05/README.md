# AI-Assisted Candidate Persona — Junior Java Developer

## 📌 Project Overview

This project demonstrates how AI can assist an IT recruiter in creating an ideal candidate persona for a **Junior Java Developer** role.

The project focuses on identifying the candidate's core requirements and expanding sourcing possibilities through:

* Candidate persona creation
* Must-have and good-to-have skills
* Similar job titles
* Related technical skills
* Alternative keywords
* Transferable skills
* Boolean search strings
* AI-assisted recruitment prompts

---

## 🎯 Objective

The objective is to create a structured candidate persona that helps an IT recruiter:

1. Understand the ideal candidate profile
2. Identify essential technical skills
3. Discover alternative job titles
4. Expand sourcing keywords
5. Identify transferable skills
6. Build better Boolean searches
7. Improve candidate sourcing

## 👤 Ideal Candidate Persona

The ideal candidate is a fresher or junior-level developer with a BE/BTech/BCA/MCA background and 0–2 years of experience.

The candidate should have a strong foundation in Java, OOP and SQL, along with basic Git/GitHub knowledge.

Exposure to Spring Boot, REST APIs and database technologies is desirable.

The candidate may demonstrate their skills through:

* Academic projects
* Internships
* Personal projects
* Certifications
* GitHub repositories

## 🤖 AI-Assisted Recruitment

AI was used in this project to help expand the candidate persona and identify:

* Similar job titles
* Related technical skills
* Alternative keywords
* Transferable skills
* Candidate backgrounds
* Boolean search terms

### AI Prompt

```text
Act as an IT Recruiter and Talent Acquisition Specialist.

I am sourcing candidates for:

Role: Junior Java Developer
Experience: 0–2 years
Education: BE/BTech/BCA/MCA

Must-have skills:
Java, OOP, SQL, Basic Git

Good-to-have skills:
Spring Boot, REST APIs

Identify:
1. Similar job titles
2. Related technical skills
3. Alternative keywords
4. Alternative job-title keywords
5. Potential transferable skills
6. Relevant candidate backgrounds
7. Boolean search keywords

Separate must-have requirements from good-to-have requirements.
Focus only on job-related qualifications.
```
